## Core MusicBrainz Picard Features

- **A Folder You Add:** Load audio files you may retag. Picard looks up public release data. It does not download the songs.
- **A Match You Check:** A suggested album is a guess until you look at the track list and the lengths.
- **Save When It Matches:** Writing tags changes the files. Do it after the match is right, and keep a copy if these are the only masters.
- **A Cluster First:** Group files that belong together so one wrong album does not rename a mixed folder.

---

## About MusicBrainz Picard

Picard helps you put titles, artists, and album names on music files you already own. The database is public metadata. The audio has to be on your disk already, from a purchase, a disc you were allowed to rip, or a recording you made. Matching a commercial album you do not have the files for will not produce those files.

Look at the proposal before you save. A compilation and a studio album can share a title. The wrong one will rename every track into a mess you then have to undo. Work on a copy of a small folder the first time so a bad save is only a bad copy.

If a file has no acoustic match, leave it unmatched. Forcing the nearest album is how a live recording gets the studio track names.

## Getting Started with MusicBrainz Picard

Prerequisites: A copy of one album you own, in its own folder.

1. **Add That Folder:** Do not add every drive.
2. **Cluster and Look Up:** Read the suggested release name and the track count.
3. **Save Only If It Matches:** If the lengths or the titles are wrong, do not save.
4. **Play One File:** Confirm the tag in your player. Keep the untagged copy until you are satisfied.

## Professional & Personal Use Cases

- **A Ripped Disc You Own:** Replace Track01 with the real title after you confirm the release.
- **A Purchased Download:** Fix a folder the shop named poorly.
- **A Mixed Folder:** Cluster first so two albums are not saved as one.
- **A Library You Care About:** Tag a copy, then replace the originals only when the names are right.
